Hamza, here's the clean sequence from your exact current state. The blocker is that Autopsy 4.22.1 needs `sleuthkit-4.14.0.jar` and your old deb (`sleuthkit-java_4.12.1-1_amd64.deb`) is the wrong version.

**Step 1 — Clean up the broken install directory**

```bash
rm -rf ~/autopsy
```

**Step 2 — Download the correct Sleuth Kit Java bindings (4.14.0)**

```bash
cd ~
wget https://github.com/sleuthkit/sleuthkit/releases/download/sleuthkit-4.14.0/sleuthkit-java_4.14.0-1_amd64.deb
```

If `wget` can't reach GitHub from the VM, download it on the Windows host from that same URL and drop it into your shared folder, then copy from `/mnt/shared/`.

**Step 3 — Install the deb**

```bash
sudo dpkg -i ~/sleuthkit-java_4.14.0-1_amd64.deb
```

If it complains about missing dependencies, follow with:

```bash
sudo apt-get install -f -y
```

**Step 4 — Verify the jar landed**

```bash
ls /usr/share/java/sleuthkit-4.14.0.jar
```

You should see that file. If it's there, you're unblocked.

**Step 5 — Re-run the Autopsy installer**

```bash
cd ~/autopsy-4.22.1
bash linux_macos_install_scripts/install_application.sh
```

**Step 6 — Launch Autopsy**

```bash
~/autopsy/bin/autopsy
```

**Step 7 — When Autopsy opens, add a new case, then add the image at:**

```
/mnt/shared/lubuntu_forensic.dd
```

If `/mnt/shared/` isn't mounted after a reboot, verify it first with `ls /mnt/shared/lubuntu_forensic.dd` before pointing Autopsy at it.
