Snap can work, but the old problem was snap's sandboxing blocks access to `/mnt/shared/`. The fix is to mount the shared folder **inside your home directory** instead, where snap can read it. Here's the full guide from reboot:

---

**Step 1 — Remount shared folder to a snap-friendly path**

```bash
mkdir -p ~/shared
sudo mount -t vboxsf DF_Shared ~/shared
ls ~/shared/lubuntu_forensic.dd
```

You must see the file before continuing.

**Step 2 — Install Autopsy via snap**

```bash
sudo snap install autopsy
```

If it's already installed, skip to Step 3.

**Step 3 — Give snap access to home files**

```bash
sudo snap connect autopsy:removable-media
sudo snap connect autopsy:home
```

**Step 4 — Launch Autopsy**

```bash
autopsy
```

**Step 5 — In the Autopsy GUI**

New Case → Add Data Source → point it to:

```
/home/vboxuser/shared/lubuntu_forensic.dd
```

Not `/mnt/shared/`, not the symlink — use the full path above.

---

**Meanwhile, in a second terminal, start the SHA1 hash:**

```bash
sudo mount -t vboxsf DF_Shared ~/shared
sha1sum ~/shared/lubuntu_forensic.dd
```
