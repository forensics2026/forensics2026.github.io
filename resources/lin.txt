Here is everything, from scratch, based only on what is confirmed working. Copy and paste each block one at a time.

---

**Step 1 — Confirm the jar is still there**

```bash
ls /usr/share/java/sleuthkit-4.14.0.jar
```

If it says "No such file", stop and tell me. If you see the path, continue.

---

**Step 2 — Remove any old install**

```bash
rm -rf ~/autopsy
```

---

**Step 3 — Try the installer with explicit flags**

```bash
export JAVA_HOME=/usr/lib/jvm/java-21-openjdk-amd64
cd ~/autopsy-4.22.1
bash linux_macos_install_scripts/install_application.sh -i ~/autopsy -j /usr/lib/jvm/java-21-openjdk-amd64
```

If this prints "Usage:" again instead of installing, skip to Step 3B.

**Step 3B — Use the other installer instead**

```bash
cd ~/autopsy-4.22.1
chmod +x unix_setup.sh
bash unix_setup.sh
```

---

**Step 4 — Check what got created**

```bash
ls ~/autopsy/bin/autopsy
```

If that file doesn't exist, try:

```bash
ls ~/autopsy-4.22.1/bin/autopsy
```

Whichever path shows the file is your launch path.

---

**Step 5 — Launch Autopsy**

Use whichever path worked in Step 4:

```bash
~/autopsy/bin/autopsy
```

or

```bash
~/autopsy-4.22.1/bin/autopsy
```

---

**Step 6 — Confirm the image is accessible**

```bash
ls /mnt/shared/lubuntu_forensic.dd
```

If it says "No such file":

```bash
sudo mount -t vboxsf DF_Shared /mnt/shared
ls /mnt/shared/lubuntu_forensic.dd
```

---

**Step 7 — In the Autopsy GUI**

New Case → Add Data Source → point it to:

```
/mnt/shared/lubuntu_forensic.dd
```
