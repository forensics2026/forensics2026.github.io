The problem is that `apt-get install -f` couldn't find all the dependencies on Debian 13, so it **removed** the package instead of fixing it. The jar is gone.

We can work around this by extracting just the jar from the deb manually and placing it where the installer expects it.

**1. Extract the jar from the deb**

```bash
mkdir /tmp/tsk
dpkg-deb -x ~/sleuthkit-java_4.14.0-1_amd64.deb /tmp/tsk
find /tmp/tsk -name "*.jar"
```

**2. Copy the jar to where Autopsy looks for it**

```bash
sudo cp /tmp/tsk/usr/share/java/sleuthkit-4.14.0.jar /usr/share/java/
```

**3. Verify it's there**

```bash
ls /usr/share/java/sleuthkit-4.14.0.jar
```

**4. Clean up old install and re-run the Autopsy installer**

```bash
rm -rf ~/autopsy
export JAVA_HOME=/usr/lib/jvm/java-21-openjdk-amd64
cd ~/autopsy-4.22.1
bash linux_macos_install_scripts/install_application.sh
```

**5. Verify and launch**

```bash
ls ~/autopsy/bin/autopsy
~/autopsy/bin/autopsy
```
