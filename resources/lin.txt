## Install Autopsy 4 via Snap (Easiest Method)

```bash
# 1. Install snap if not already present
sudo apt update
sudo apt install snapd -y

# 2. Install Autopsy 4
sudo snap install autopsy

# 3. Connect required snap interfaces (Autopsy needs disk access)
snap connections autopsy | sed -nE 's/^[^ ]* *([^ ]*) *- *- *$/\1/p' | xargs -I{} sudo snap connect {}

# 4. Launch (first run use --nosplash to avoid hidden dialog bug)
autopsy --nosplash
```

If snap gives network issues inside the VM, the alternative is manual install from GitHub:
```bash
# Download from https://github.com/sleuthkit/autopsy/releases
# Get the .zip + the matching sleuthkit-java .deb
# Then run the install_application.sh script
```

But try snap first — it handles all dependencies automatically.

## First Run — Create Case & Add Image

1. Autopsy 4 opens as a full desktop GUI (like on Windows)
2. **New Case** → Case Name: `CW2_Investigation` → Base Directory: pick anywhere with space (e.g. `/mnt/shared/autopsy_cases/`)
3. **Add Data Source** → select **Disk Image or VM File** → path: `/mnt/shared/lubuntu_forensic.dd`
4. **Ingest Modules** — run these (untick the rest to save time on 6 GB RAM):
   - Recent Activity
   - File Type Identification (by signature)
   - Keyword Search
   - Email Parser
   - Encryption Detection
   - Picture Analyzer
   - Extension Mismatch Detector ← this is the one that catches the JPEG-as-.dll files
5. Click **Finish** and let it run. On 6 GB RAM with a 20 GB image this could take 20–40 minutes.

**Take a screenshot** of the New Case dialog or the ingest modules running.
