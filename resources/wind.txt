The shared folder is working — all 7 VMDK files are visible at `/mnt/shared/`. You're now on **Step 2** of the guide. Since your mount point is `/mnt/shared/` (not `/media/sf_DF_Shared/`), run these commands in order:

**Step 2 — Combine the split VMDK:**
```bash
# Create working directories
mkdir -p ~/evidence ~/forensic_images

# Install qemu-utils
sudo apt-get install qemu-utils -y

# Convert split VMDK → single raw image (point to the descriptor file)
qemu-img convert -f vmdk -O raw "/mnt/shared/Lubuntu 64-bit.vmdk" ~/evidence/lubuntu_combined.raw
```

This will take a few minutes (it's combining ~6.5 GB). Once done:

**Step 3 — Hash the original:**
```bash
md5sum ~/evidence/lubuntu_combined.raw | tee ~/evidence/original_hashes.txt
sha256sum ~/evidence/lubuntu_combined.raw | tee -a ~/evidence/original_hashes.txt
```
